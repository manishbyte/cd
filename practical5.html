Practical 5: Target Code Generator for Intel 8086 Assembly

Step 1: Create Practical Workspace Directory

Open the terminal and create the Practical 5 directory:

Ubuntu Bash Terminal 
mkdir -p ~/Desktop/CompilerLab/Practical5
cd ~/Desktop/CompilerLab/Practical5

Step 2: Create Test Assignment Input (input.txt)

Open the editor to create the expression input file:

Ubuntu Command 
gedit input.txt

Paste the expressions below (ensure you press Enter after the last line) and save:

input.txt 
a=b+c
x=y-z
p=q*r
m=n/d
k=j

Step 3: Create Lexer Specification (exp.l)

Create the lexical scanner in your editor:

Ubuntu Command 
gedit exp.l

Paste the following Lex program and save:

exp.l 
%{
#include <stdio.h>
#include <string.h>
#include "y.tab.h"
%}

%%
[a-zA-Z_][a-zA-Z0-9_]*|[0-9]+ {
    strncpy(yylval.vname, yytext, sizeof(yylval.vname) - 1);
    yylval.vname[sizeof(yylval.vname) - 1] = '\0';
    return NAME;
}
[ \t\r]     ;
\n          { return '\n'; }
.           { return yytext[0]; }
%%

int yywrap(void)
{
    return 1;
}

Step 4: Create Code Generator Parser (exp.y)

Open the parser file in your editor:

Ubuntu Command 
gedit exp.y

Paste the complete syntax-directed translation grammar:

exp.y 
%{
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
int yylex(void);
void yyerror(const char *s);
extern FILE *yyin;
%}

%union {
    char vname[32];
}

%left '+' '-'
%left '*' '/'

%token <vname> NAME
%type  <vname> expression

%%
input
    : line '\n' input
    | line
    | '\n' input
    | /* empty */
    ;

line
    : NAME '=' expression
      {
          printf("MOV %s, AX\n\n", $1);
      }
    ;

expression
    : NAME '+' NAME
      {
          printf("MOV AX, %s\n", $1);
          printf("ADD AX, %s\n", $3);
          strcpy($$, $1);
      }
    | NAME '-' NAME
      {
          printf("MOV AX, %s\n", $1);
          printf("SUB AX, %s\n", $3);
          strcpy($$, $1);
      }
    | NAME '*' NAME
      {
          printf("MOV AX, %s\n", $1);
          printf("MOV BX, %s\n", $3);
          printf("MUL BX\n");
          strcpy($$, $1);
      }
    | NAME '/' NAME
      {
          printf("MOV AX, %s\n", $1);
          printf("MOV DX, 0\n");
          printf("MOV BX, %s\n", $3);
          printf("DIV BX\n");
          strcpy($$, $1);
      }
    | NAME
      {
          printf("MOV AX, %s\n", $1);
          strcpy($$, $1);
      }
    ;
%%

int main(int argc, char *argv[])
{
    FILE *fpInput;
    const char *fname = (argc > 1) ? argv[1] : "input.txt";

    fpInput = fopen(fname, "r");
    if (fpInput == NULL) {
        printf("File read error: cannot open %s\n", fname);
        exit(1);
    }
    yyin = fpInput;
    yyparse();
    fclose(fpInput);
    return 0;
}

void yyerror(const char *s)
{
    printf("Invalid expression\n");
}

Step 5: Multi-Stage Compilation Pipeline

Run the generator and build the executable with GCC:

Terminal Build Commands 
bison -y -d exp.y
flex exp.l
gcc y.tab.c lex.yy.c -o exp

Step 6: Execution & Expected Assembly Output

Execute the program against input.txt:

Terminal Execution 
./exp

The compiler generates the complete 8086 assembly sequence:

Generated 8086 Assembly Code 
MOV AX, b
ADD AX, c
MOV a, AX

MOV AX, y
SUB AX, z
MOV x, AX

MOV AX, q
MOV BX, r
MUL BX
MOV p, AX

MOV AX, n
MOV DX, 0
MOV BX, d
DIV BX
MOV m, AX

MOV AX, j
MOV k, AX
