Practical 4: Context Free Grammar for Language L = { 0ⁿ1ⁿ | n ≥ 1 }

Step 1: Create Practical Workspace Directory

Open the Ubuntu terminal and set up the dedicated folder:

Ubuntu Bash Terminal 
mkdir -p ~/Desktop/CompilerLab/Practical4
cd ~/Desktop/CompilerLab/Practical4

Step 2: Create Token Recognizer (cfg.l)

Open the text editor for the lexer:

Ubuntu Command 
gedit cfg.l

Paste the following Flex code and save:

cfg.l 
%{
#include "y.tab.h"
%}

%%
"0"     { return ZERO; }
"1"     { return ONE; }
\n      { return NL; }
.       { return yytext[0]; }
%%

int yywrap(void)
{
    return 1;
}

Step 3: Create CFG Grammar Specification (cfg.y)

Open the parser file in the editor:

Ubuntu Command 
gedit cfg.y

Paste the following Yacc grammar specification and save:

cfg.y 
%{
#include <stdio.h>
int flag = 0;
int yylex(void);
void yyerror(const char *s);
%}

%token ONE ZERO NL

%%
str1 : str2 nl ;

str2 : ZERO str2 ONE
     | ZERO ONE
     ;

nl   : NL { YYACCEPT; } ;
%%

int main(void)
{
    printf("\nEnter string (any combination of 0 and 1)\n");
    yyparse();
    if (flag == 0)
        printf("\nEntered string is Valid for L={0^n1^n}\n\n");
    return 0;
}

void yyerror(const char *s)
{
    printf("\nEntered string is Invalid for L={0^n1^n}\n\n");
    flag = 1;
}

Step 4: Compile with Bison, Flex, and GCC

Compile the parser header, link with the lexer, and build the target binary:

Terminal Build Pipeline 
bison -y -d cfg.y
flex cfg.l
gcc y.tab.c lex.yy.c -o cfg

Step 5: Test Verification Matrix

Execute the program with ./cfg and verify language recognition:

Terminal Execution 
./cfg
Input String Analysis / Condition Result
01 n = 1 (Exactly one '0' followed by one '1') Valid
0011 n = 2 (Two '0's followed by two '1's) Valid
000111 n = 3 (Three '0's followed by three '1's) Valid
0101 Alternating sequence — violates grammar order Invalid
001 Unbalanced — two '0's but only one '1' Invalid
10 Inverted order — '1' precedes '0' Invalid
