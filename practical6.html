Practical 6: Deterministic Finite Automaton (DFA) for Divisibility by 3

Step 1: Create Practical Workspace Directory

Open the Ubuntu terminal and set up the Practical 6 directory:

Ubuntu Bash Terminal 
mkdir -p ~/Desktop/CompilerLab/Practical6
cd ~/Desktop/CompilerLab/Practical6

Step 2: Create Token Recognizer (dfa.l)

Open the editor to create the token classification file:

Ubuntu Command 
gedit dfa.l

Paste the following Flex code and save:

dfa.l 
%{
#include "y.tab.h"
%}

%%
[0369]  { return ZERO; }
[147]   { return ONE; }
[258]   { return TWO; }
\n      { return NL; }
.       { return yytext[0]; }
%%

int yywrap(void)
{
    return 1;
}

Step 3: Create State Machine Parser (dfa.y)

Open the state automaton definition file in the editor:

Ubuntu Command 
gedit dfa.y

Paste the complete state-transition grammar:

dfa.y 
%{
#include <stdio.h>
int yylex(void);
void yyerror(const char *s);
%}

%token ZERO ONE TWO NL
%start q0

%%
q0 : ZERO q0
   | ONE q1
   | TWO q2
   | NL { printf("Number is divisible by 3\n"); YYACCEPT; }
   ;

q1 : ZERO q1
   | ONE q2
   | TWO q0
   | NL { printf("Number is not divisible by 3, remainder is 1\n"); YYACCEPT; }
   ;

q2 : ZERO q2
   | ONE q0
   | TWO q1
   | NL { printf("Number is not divisible by 3, remainder is 2\n"); YYACCEPT; }
   ;
%%

int main(void)
{
    printf("\nEnter Decimal number to check divisibility by 3:\n");
    yyparse();
    return 0;
}

void yyerror(const char *s)
{
    printf("\nInvalid input, enter only decimal digits\n");
}

Step 4: Multi-Stage Compilation Pipeline

Compile Bison first to produce header tokens, then Flex, and link with GCC:

Terminal Build Commands 
bison -y -d dfa.y
flex dfa.l
gcc y.tab.c lex.yy.c -o dfa

Step 5: Execution & Test Verification Matrix

Run the compiled binary:

Terminal Run Command 
./dfa

Test with various decimal numbers to verify state transitions:

Input Number Modulo Sum Calculation Terminal Output Evaluation
