Practical 3: Arithmetic Calculator using LEX and YACC

Step 1: Create Practical Workspace Directory

Open the terminal and create the Practical 3 directory:

Ubuntu Bash Terminal 
mkdir -p ~/Desktop/CompilerLab/Practical3
cd ~/Desktop/CompilerLab/Practical3

Step 2: Create Lexical Scanner (calculator.l)

Launch the editor to create the token recognizer:

Ubuntu Command 
gedit calculator.l

Paste the following Lex code and save:

calculator.l 
%{
#include <stdio.h>
#include <stdlib.h>
#include "y.tab.h"
%}

%%
[0-9]+      { yylval = atoi(yytext); return NUMBER; }
[ \t\r]     ;
\n          { return 0; }
.           { return yytext[0]; }
%%

int yywrap(void)
{
    return 1;
}

Step 3: Create Parser Grammar (calculator.y)

Open the parser grammar file in your editor:

Ubuntu Command 
gedit calculator.y

Paste the following Yacc specification and save:

calculator.y 
%{
#include <stdio.h>
#include <stdlib.h>
int flag = 0;
int yylex(void);
void yyerror(const char *s);
%}

%token NUMBER
%left '+' '-'
%left '*' '/' '%'
%right UMINUS

%%
Arithmetic_Expression
    : E { printf("\nResult = %d\n", $1); }
    ;

E
    : E '+' E   { $$ = $1 + $3; }
    | E '-' E   { $$ = $1 - $3; }
    | E '*' E   { $$ = $1 * $3; }
    | E '/' E   {
                    if ($3 == 0) { yyerror("division by zero"); YYABORT; }
                    $$ = $1 / $3;
                }
    | E '%' E   {
                    if ($3 == 0) { yyerror("modulo by zero"); YYABORT; }
                    $$ = $1 % $3;
                }
    | '-' E %prec UMINUS { $$ = -$2; }
    | '(' E ')' { $$ = $2; }
    | NUMBER    { $$ = $1; }
    ;
%%

int main(void)
{
    printf("\nEnter an arithmetic expression:\n");
    printf("Operations allowed: +, -, *, /, %% and brackets\n\n");
    yyparse();
    if (flag == 0)
        printf("\nEntered arithmetic expression is Valid\n");
    return 0;
}

void yyerror(const char *s)
{
    printf("\nEntered arithmetic expression is Invalid (%s)\n", s);
    flag = 1;
}

Step 4: Multi-Stage Compilation Pipeline

Order of Operations Matters: You must run bison -y -d first to generate y.tab.h before compiling calculator.l with Flex, otherwise Flex will encounter an undefined symbol error.
Terminal Compilation Pipeline 
bison -y -d calculator.y
flex calculator.l
gcc y.tab.c lex.yy.c -o calculator

Note: Compiler warning notices can be safely ignored; only lines marked error impede executable output.

Step 5: Execution & Test Verification Matrix

Run the compiled calculator binary:

Terminal Run Command 
./calculator

Type any expression at the prompt and press Enter:

Input Expression Terminal Output Validation Result
2+3*4 Result = 14 Valid (Multiplication precedes addition)
(2+3)*4 Result = 20 Valid (Parentheses override precedence)
-5+3 Result = -2 Valid (Unary minus handled)
10/0 Entered arithmetic expression is Invalid (division by zero) Invalid (Zero division trapped cleanly)
5+ Entered arithmetic expression is Invalid (syntax error) Invalid (Missing operand)
