Practical 2: Lexical Analyzer to Identify Numbers

Step 1: Create Practical Workspace Directory

Set up the directory inside the Ubuntu terminal:

Ubuntu Bash Terminal 
mkdir -p ~/Desktop/CompilerLab/Practical2
cd ~/Desktop/CompilerLab/Practical2

Step 2: Create Test Input Dataset (input.txt)

Generate the test dataset covering all positive, negative, exponential, and invalid cases:

Ubuntu Command 
gedit input.txt

Paste the following test values and save:

input.txt 
0b1010
0x1F
017
42
-7
+9
3.14
-56.78
12e5
1.5e-3
abc
12abc

Step 3: Create Lexer Program (program2.l)

Open the editor to create the Flex specification:

Ubuntu Command 
gedit program2.l

Paste the complete Flex source code below:

program2.l 
%option noyywrap
%{
#include <stdio.h>
%}

Binary      0[bB][01]+
Hex         0[xX][0-9A-Fa-f]+
Octal       0[0-7]+
Exponent    [-+]?([0-9]+"."?[0-9]*|"."[0-9]+)[eE][-+]?[0-9]+
Float       [-+]?[0-9]*"."[0-9]+
Integer     [-+]?[0-9]+

%%
{Binary}    { printf("Binary number        : %s\n", yytext); }
{Hex}       { printf("Hexadecimal number   : %s\n", yytext); }
{Octal}     { printf("Octal number         : %s\n", yytext); }
{Exponent}  { printf("Exponent number      : %s\n", yytext); }
{Float}     {
                if (yytext[0] == '-')
                    printf("Negative Float       : %s\n", yytext);
                else
                    printf("Positive Float       : %s\n", yytext);
            }
{Integer}   {
                if (yytext[0] == '-')
                    printf("Negative Integer     : %s\n", yytext);
                else
                    printf("Positive Integer     : %s\n", yytext);
            }
[ \t\r\n]+  ;
[^ \t\r\n]+ { printf("Invalid              : %s\n", yytext); }
%%

int main(int argc, char *argv[])
{
    FILE *fp;
    if (argc < 2) {
        printf("Usage: %s input.txt\n", argv[0]);
        return 1;
    }
    fp = fopen(argv[1], "r");
    if (fp == NULL) {
        printf("Cannot open input file\n");
        return 1;
    }
    yyin = fp;
    yylex();
    fclose(fp);
    return 0;
}

Step 4: Compile and Execute on Ubuntu

Run the toolchain commands sequentially:

Terminal Build & Run 
flex program2.l
gcc lex.yy.c -o a.out
./a.out input.txt

Expected Terminal Output

Every line from input.txt is analyzed without regex interference:

Standard Output 
Binary number        : 0b1010
Hexadecimal number   : 0x1F
Octal number         : 017
Positive Integer     : 42
Negative Integer     : -7
Positive Integer     : +9
Positive Float       : 3.14
Negative Float       : -56.78
Exponent number      : 12e5
Exponent number      : 1.5e-3
Invalid              : abc
Invalid              : 12abc
